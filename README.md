# Smart Street Light Using Arduino

A prototype street light that switches automatically, to save electricity.

## How it works
- An LDR (light sensor) detects the ambient light level.
- An HC-SR04 ultrasonic sensor detects nearby objects.
- The Arduino Uno reads both sensors and controls the LED street light.

## Components
- Arduino Uno
- LDR (photoresistor)
- HC-SR04 ultrasonic sensor
- LED
- Resistors
- Breadboard and jumper wires
- 9V battery

## Tools
- Tinkercad (circuit design and simulation)
- Arduino IDE (programming)
